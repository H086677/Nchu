# 昌航逐梦指南 · 南昌航空大学校园人生模拟器

南昌航空大学（NCHU）主题的校园人生模拟器。纯 HTML / CSS / JavaScript，零依赖、零构建，双击 `index.html` 即可运行。

> 同人作品，不是南昌航空大学官方网站。

## 在线体验

https://h086677.github.io/Nchu/

## 玩法

### 开局四步

1. **取名** —— 名字会印在结局的登机牌上
2. **加点** —— 10 点自由分配到五项属性（单项上限 5，基础各 3 点）
3. **选专业** —— 24 个专业，各带属性加成
4. **抽天赋** —— **58 张**天赋卡随机抽 5 张，挑 2 张带走，叠加到初始属性

### 四年剧情

8 个学期，**58 个主线事件** + **8 个社团**各 3 个专属事件 + **38 个随机事件**。选项有属性检定：**属性 + d20 ≥ 难度值（DC）** 即成功。

每学期不会把该学期所有事件都演一遍 —— 每学期固定 3–4 个事件位，其中「锚点事件」必出（军训、百团大战、四级、金工实习、专业分流、保研抉择、毕设开题、毕业答辩），其余从该学期事件池里**随机抽取**，顺序也打乱。

| 学期 | 锚点事件 | 该学期其他事件（随机抽 2–3 个） |
|---|---|---|
| 大一上 | 军训、百团大战（选社团） | 航空菁英特训班、四个人的宿舍、宿舍躺平、迷路的第一天、生活费不够、熄灯之后 |
| 大一下 | 第一次四级 | 翘课的代价、六级报名、第一个暑假、春天的感冒、室友借钱、暑假去哪儿 |
| 大二上 | 金工实习 | 六级与专业课、通宵的排位、兼职的机会、实验室搬砖、家里的电话、开黑的夜晚 |
| 大二下 | 专业方向分流 | 数学建模竞赛、图书馆四楼、进实验室、挂科了、竞选部长、还有一个人 |
| 大三上 | —（全随机） | 挑战杯、最难的一学期、学业预警通知、电子设计竞赛、投出去的简历、各走各的、体检报告 |
| 大三下 | 保研 / 考研 / 工作 / 考公 / 创业 | 生产实习、六月的雨、第一篇论文、暑期实习、一个链接、拒稿信 |
| 大四上 | 毕业设计开题 | 秋招、考研冲刺、要不要出国、第一个 offer、过年回家、出分那天 |
| 大四下 | 毕业答辩 | 最后一次班会、毕业旅行、一个念头、查重报告、最后一次补考、散伙饭、空宿舍 |

社团：航模队、数学建模协会、机器人协会、青年志愿者协会、书法协会、辩论队、青年马克思主义者学习研究会、跑步协会。

### 降低重复度

两个机制让每局都不一样：

1. **抽样** —— 每学期只演 3–4 个事件，不是全量播放
2. **跨周目记忆** —— 出场过的事件记在 `localStorage`（`nchu-seen`），下一局优先抽没见过的

实测相邻两局的事件重合率从 **46.9%** 降到 **36.3%**；连玩三局累计见过的事件数从 57.1 升到 72.5（总池 96）。

### 学业风险

逃课、躺平、通宵等负面选项会累积**学业风险**（0–100）。每个负面选项都会在按钮上标出「学业风险 +N」，选之前就能看到代价。学期末结算：

- **≥ 70** —— 收到学业预警，学习 -1，风险按比例消退到 30%
- **累计 3 次预警** —— 直接劝退
- **≥ 100** —— 当场劝退

劝退会进入「劝退通知」结局。风险条在游戏页左侧实时显示，正常（绿）/ 预警（琥珀）/ 危险（红）。

各策略下的劝退率（每档 600 局模拟）：全优 0%、偶尔冒险 4.5%、偶尔摆烂 20.3%、随机乱选 64.8%、半摆烂 97.5%、全摆烂 100%。

### 随机事件

每学期有 **70%** 概率插入一个随机事件，一局内不重复。共 38 个，覆盖恋爱、挫折、意外之喜与生活日常：

- **恋爱** —— 表白、小别离
- **挫折** —— 生病、挂科、丢东西、室友冲突、手机摔坏、闹钟没响、钱包丢了、车被偷、小组作业被坑、导师发火、谣言
- **意外之喜** —— 奖学金、捡到东西、被老师点名参赛、抽奖、老师记得你
- **生活** —— 图书馆闭馆曲、通宵、志愿活动、下雨、宿舍卫生检查、断网、学长送书、走错教室、雨天散步、社团活动、考前泄题、南昌的暴雨

### 结局

**15 种结局**，依最终属性与关键选择判定：

| 类型 | 结局 |
|---|---|
| 正常 | 航空报国、凌云直上、脚踏实地、另辟蹊径、平凡四年 |
| 特殊 | 传奇、创业、双向奔赴、上岸、科研之路、体制内、越洋 |
| 负面 | 劝退通知（学业风险满 / 三次预警）、另一种选择（主动退学） |
| 隐藏 | 卢校长？（彩蛋） |

### 成就收集

**47 个成就**，跨局持久化（`localStorage`），分 9 类：入学开局 4、学业 7、竞赛 4、社团 4、生活 7、挫折 5、职业 4、结局收集 9、隐藏 3。达成时右下角弹出提示，成就页有总进度条。

隐藏成就包含「卢校长？」「全收集」「十世轮回」，未解锁时显示为 `？？？`。

## 五项属性

| 属性 | 英文 | 含义 |
|---|---|---|
| 学习 | DIL | 上课、自习、看书 |
| 动手 | PRA | 实验、实习、做东西 |
| 品行 | INT | 原则、纪律、责任心 |
| 创意 | INN | 想法、探索、折腾 |
| 体能 | STA | 精力、耐力、身体 |

## 卢超彩蛋

把名字填成 **卢超**：五项属性直接拉满、天赋全为 SSR 且可全选、专业锁定为测控技术与仪器，确认后直接通关，解锁隐藏结局「卢校长？」与隐藏成就。
