# 昌航逐梦指南 · 南昌航空大学校园人生模拟器

南昌航空大学（NCHU）主题的校园人生模拟器。纯 HTML / CSS / JavaScript，零依赖、零构建，双击 `index.html` 即可运行。

> 同人作品，不是南昌航空大学官方网站。

## 在线体验

https://h086677.github.io/Nchu/

## 玩法

### 开局四步

1. **取名** —— 名字会印在结局的登机牌上
2. **加点** —— 10 点自由分配到五项属性（单项上限 5，基础各 3 点）
3. **选专业** —— 24 个专业，各带属性加成
4. **抽天赋** —— 28 张天赋卡随机抽 5 张，挑 2 张带走，叠加到初始属性

### 四年剧情

8 个学期，15 个主线事件 + 6 个社团各 3 个专属事件。选项有属性检定：**属性 + d20 ≥ 难度值（DC）** 即成功。

| 学期 | 事件 |
|---|---|
| 大一上 | 军训、航空菁英特训班、百团大战（选社团） |
| 大一下 | 第一次四级 |
| 大二上 | 六级、金工实习 |
| 大二下 | 数学建模竞赛、专业方向分流 |
| 大三上 | 挑战杯、最难的一学期 |
| 大三下 | 生产实习、保研 / 考研 / 工作 |
| 大四上 | 毕业设计开题、秋招 |
| 大四下 | 毕业答辩 |

社团：航模队、数学建模协会、机器人协会、青年志愿者协会、书法协会、辩论队。

结局共 6 种，依最终属性与关键选择判定。

## 五项属性

| 属性 | 英文 | 含义 |
|---|---|---|
| 笃学 | DIL | 课堂、自习、理论功底 |
| 力行 | PRA | 动手、实操、工程能力 |
| 守正 | INT | 原则、纪律、责任感 |
| 求新 | INN | 创意、探索、跨界 |
| 体质 | STA | 精力、耐力、身体状态 |

## 卢超彩蛋

把名字填成 **卢超**：五项属性直接拉满、天赋全为 SSR 且可全选、专业锁定为测控技术与仪器，确认后直接通关，解锁隐藏结局「卢校长？」与隐藏成就。
