# 昌航逐梦指南

南昌航空大学主题的校园人生模拟器首步网站。纯 HTML / CSS / JavaScript，无需安装依赖或构建。

## 打开网站

直接用浏览器打开 `index.html` 即可体验。

## 已实现

- 输入名字，空名字验证
- 24 张昌航专业选择卡片（专业名称依据学校 2026 年本科招生专业目录整理）
- 24 项校园天赋，随机 3 张天赋卡、翻卡动画、两次换一批和随机选择
- 返回上一步、重新启程
- 完成后的「敬请期待」页面，展示名字、专业和天赋
- 手机/电脑自适应、深浅色主题切换

## 发布

把整个 `nchu-campus-life` 文件夹上传到 GitHub Pages、Cloudflare Pages、Vercel 或任意静态网站服务器即可。入口文件是 `index.html`。

字体使用 Google Fonts 的 Noto Serif SC；加载失败时自动使用本机宋体，其余资源均在本地。

校徽取自[南昌航空大学招生信息网](https://zsw.nchu.edu.cn/)官方页头图片，本地文件为 `assets/nchu-emblem.png`。专业名称核对自学校招生信息网的[《南昌航空大学2026年本科招生专业目录》](https://zsw.nchu.edu.cn/index.php?sys=home&module=article&param=51&act=view&article_id=dKVwYLbXG952)。本网站为校园主题创意页面，不是学校官方网站。
